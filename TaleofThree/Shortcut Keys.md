# Shortcut Keys

Here is the definitive shortcut and function reference for **4AM**. This is organized by context so you know exactly what works where.

---

### 🌍 Global Navigation
*These shortcuts work regardless of which mode you are currently using.*

| Shortcut | Function | Description |
| :--- | :--- | :--- |
| **Ctrl + Shift + F** | **The Oracle** | Open vault-wide search to find any word in any file. |
| **Ctrl + D** | **Focus Mode** | Hides Sidebar and HUD for a distraction-free screen. |
| **Shift + Tab** | **Ghost HUD** | Quickly shows or hides the floating HUD window. |
| **Ctrl + Shift + H**| **Toggle Float** | Pops the HUD out into its own window (for dual monitors). |
| **F11** | **Fullscreen** | Toggles standard windowed mode and total fullscreen. |

---

### 📝 Markdown Editor
*Shortcuts specific to writing and managing lore documents.*

| Shortcut | Function | Description |
| :--- | :--- | :--- |
| **Ctrl + E** | **The Flip** | Switches the active pane between Edit and Reading mode. |
| **Ctrl + F** | **Local Search** | Opens a small search bar in the title bar of the active pane. |
| **Ctrl + Shift + E**| **Center Align** | Wraps selected text in `<center>` tags automatically. |
| **Alt + Scroll** | **Live Resize** | Hover over an image link to change its size (e.g., `\|300`). |
| **Ctrl + Click** | **Split View** | Click a `[[Link]]` to open that note in a new pane on the right. |
| **Ctrl + V** | **Smart Paste** | Pastes text, or saves images directly to your `_attachments`. |
| **[[** | **Neural Link** | Type double brackets to trigger the file autocomplete list. |
| **Ctrl + B/I/U** | **Formatting** | Standard Markdown shortcuts for Bold, Italic, and Underline. |
Ctrl + Shift + R - removes all copy paste rainbow color

### 🎨 Canvas Mode
*Shortcuts for the infinite board used for maps and portraits.*

| Shortcut | Function | Description |
| :--- | :--- | :--- |
| **Ctrl + N** | **Spawn Card** | Creates a new text card exactly where your mouse is. |
| **Ctrl + V** | **Drop Asset** | Pastes a map or image as a physical card on the board. |
| **Middle-Click** | **Pan** | Click and drag the mouse to move around the infinite board. |
| **Ctrl + Scroll** | **Zoom** | Zoom in to see detail or zoom out for a bird's-eye view. |
| **Del / Backspace**| **Nuke** | Permanently deletes the selected card or image from the board. |
| **Bottom-Right Handle**| **Resize** | Click and drag the blue handle to resize assets (Ratio Locked). |

### ⚙️ Background Functions
*Automatic features that keep your world-building safe and organized.*

| Function | Name | How it Works |
| :--- | :--- | :--- |
| **Snapshot Engine** | **Time Machine** | Automatically saves a backup of open files every 10 minutes. |
| **Hybrid Linking** | **Ghost Folders** | If a folder and note share a name, they act as one single entry. |
| **Layout Memory** | **State Cache** | Remembers sidebar width and pane positions on every launch. |
| **Binary Vault** | **Attachments** | All images are copied to a hidden folder to keep links from breaking. |
