# 🌑 4AM
**A hyper-minimalist, multimedia worldbuilding and writing engine.**

4AM is designed for writers who need absolute focus and infinite lore connectivity. It bridges the gap between a clean writing interface (iA Writer) and a powerful lore database (Obsidian), built entirely in Python.

## ✨ Features
- **Ghost-Folders:** Folders act as notes. Lore and structure are one.
- **The Time Machine:** Silent, automated snapshots of your work every 10 minutes.
- **Neural Links:** Deep-routing `[[Wiki Links]]` with real-time autocomplete.
- **Multimedia Canvas:** An infinite board for maps, character portraits, and location markers.
- **Obsidian Syntax:** Inline image resizing using the `![[image.png|300]]` protocol.
- **Focus Mode:** A one-key toggle to nuke the UI and leave you with just your words.

## ⌨️ Master Shortcuts
- `Ctrl + D`: Toggle Focus Mode
- `Ctrl + E`: Toggle Edit/Reading Mode (Pane-specific)
- `Ctrl + Shift + F`: The Oracle (Global Vault Search)
- `Ctrl + N`: Spawn Lore Card (Canvas Mode)
- `Alt + MouseWheel`: Real-time image resizing in Edit Mode

## 🚀 Installation (Source)
1. Clone the repo: `git clone https://github.com/jamespaulamparo/4AM.git`
2. Install dependencies: `pip install PySide6 mistune`
3. Run: `python main.py`
